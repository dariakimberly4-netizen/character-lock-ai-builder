# CHARACTER//LOCK — AI Character Sheet Builder

A mobile-first character consistency web app for building reusable AI character identities.

## Features

- Character identity builder
- Face, hair, body, and outfit locks
- Visual style selector
- Character consistency score
- Reusable master prompt generator
- Saved character library using browser localStorage
- Prompt library
- Scene prompt builder
- Mobile navigation
- GitHub Pages friendly — no build step required

## How to use

Open `index.html` directly, or publish the repository with GitHub Pages.

Create a character, complete the identity fields, save it, then reuse the generated identity-lock prompt in future AI image or video workflows.

## Important

The current GitHub version generates and stores character profiles and prompt packages. Actual AI image generation requires connecting an image-generation API or service later.

## Project concept

**ONE CHARACTER IDENTITY → MANY EXPRESSIONS → MANY POSES → MANY SCENES → SAME PERSON**
